# 听书问数系统项目实战需求说明

## 1. 项目背景
面向听书平台业务场景，建设一个智能问数系统，使业务人员能够通过自然语言完成数据查询、指标统计和趋势分析。系统需要降低数据分析门槛，让用户无需编写 SQL 也能快速获得内容、播放、用户、会员、交易和运营推荐相关的数据结果。

听书业务数据覆盖有声专辑、音频章节、作者、主播、版权机构、分类标签、播放记录、收听进度、评论评分、会员套餐、内容订单、支付退款、榜单推荐、专题和搜索等业务对象，可支撑平台内容运营、用户运营和商业化分析。

## 2. 项目目标
构建一个面向听书场景的智能问数系统：
- 支持通过自然语言完成指标查询和统计分析
- 支持返回结构化结果和统计结果
- 支持围绕内容、播放、用户、会员、交易和运营推荐等主题进行分析
- 为后续扩展更多听书业务指标、分析规则和运营决策能力提供基础架构

## 3. 角色说明
### 3.1 主要使用对象
- 内容运营人员：查询专辑数量、章节数量、分类分布、作者/主播内容供给、内容更新情况等内容指标
- 用户运营人员：查询用户收藏、关注、播放、收听进度、评论评分、搜索行为等用户行为指标
- 会员与交易运营人员：查询 VIP 套餐、内容订单、支付金额、退款金额、权益开通和核销等商业化指标
- 推荐运营人员：查询榜单、推荐位、专题、搜索热词、内容曝光和内容排序效果等运营指标
- 管理人员：查看平台核心指标、趋势变化和阶段性经营分析结果

### 3.2 协同角色
- 数据运营：维护指标口径、字段释义、表关系和问数规则
- 分析人员：校验系统输出结果，补充复杂分析逻辑和异常数据解释
- 技术人员：维护数据接入、元数据管理、查询执行和系统稳定性

## 4. 功能范围
系统当前阶段需要至少支持以下能力：
- 构建语义信息：构建听书业务表元数据的语义信息，包括字段释义、表关系、指标口径和业务枚举等
- 内容指标查询：查询专辑数、章节数、主播数、作者数、内容分类分布、内容更新数量、付费内容数量等核心指标
- 播放与互动分析：查询播放次数、播放时长、完播情况、收听进度、收藏数量、关注数量、评论数量、评分、点赞、分享和举报等行为指标
- 会员与交易分析：查询 VIP 套餐数量、会员订单、内容订单、支付金额、退款金额、充值金额、钱包流水和权益记录等交易指标
- 运营推荐分析：查询热播榜、热评榜、热搜榜、免费榜、畅销榜、完结榜、推荐位、专题和搜索热词等运营数据
- 维度分析：按时间、内容分类、标签、作者、主播、语言、渠道、会员类型、专辑类型、榜单类型、推荐位等维度统计和对比数据
- 结果返回：返回查询结果、统计结果、排名结果、趋势结果和必要的解释说明

## 5. 典型业务场景
### 5.1 内容指标场景
当用户提出“平台一共有多少个有声专辑”“本月新增了多少个音频章节”“哪个分类下的专辑最多”“哪个主播的专辑数量最多”之类的问题时，系统应返回对应内容统计结果，并根据需要支持分类、作者、主播、语言和时间维度拆分。

### 5.2 播放与用户行为场景
当用户提出“最近 30 天播放次数是多少”“哪些专辑播放量最高”“用户收藏最多的专辑有哪些”“评论评分最高的内容是什么”之类的问题时，系统应基于播放会话、收听进度、评论评分、收藏关注等数据完成统计、排序和结果返回。

### 5.3 会员与交易场景
当用户提出“本月内容订单金额是多少”“VIP 月度会员销量如何”“最近 7 天退款金额是多少”“哪类内容付费转化最好”之类的问题时，系统应返回订单、支付、退款、会员套餐和权益相关指标，并支持趋势和对比分析。

### 5.4 榜单与推荐运营场景
当用户提出“热播榜周榜前十是什么”“热搜榜月榜有哪些内容”“首页每日推荐位展示了哪些专辑”“哪些专题播放量最高”之类的问题时，系统应按榜单、推荐位、专题、内容类型和周期完成查询与统计。

### 5.5 趋势对比场景
当用户提出“最近三个月播放量变化情况”“本月和上月订单金额对比”“不同渠道的付费订单差异”“各分类内容的评论量趋势”之类的问题时，系统应返回趋势数据、对比结果和排名结果。

## 6. 非功能需求
- 系统应具备基础异常处理和降级能力，避免分析失败导致整体服务不可用
- 系统应具备较好的可观测性，能够追踪问题解析、SQL 生成、查询执行和结果返回过程
- 分析结果应尽量准确、可解释、可追溯，能够说明使用的数据表、字段和统计口径
- 系统应支持同义词和业务别名识别，例如“听书”“音频”“专辑”“有声书”“节目”“章节”“主播”等表达
- 系统应支持后续扩展更多指标主题、分析规则和运营看板能力
- 对订单、支付、退款、钱包等金额类指标，应明确时间范围、状态口径和币种口径

## 7. 项目交付物
建议输出以下成果：
- 一套可运行的听书问数系统
- 基础调试页面、测试脚本或演示页面
- 听书业务元数据说明，包括表名、字段释义、主外键关系、指标口径和常见问题模板
- 项目说明文档与部署说明
- 一组覆盖内容、播放、交易、会员、推荐和搜索场景的问数测试用例

## 8. 验收标准
- 可以完成专辑数、章节数、播放次数、评论数、评分、收藏数、订单金额、退款金额、会员套餐销量等基础指标查询
- 可以完成按内容分类、标签、作者、主播、渠道、会员类型、榜单类型、推荐位、时间等维度的统计分析
- 可以完成趋势、对比、排名等常见分析请求
- 可以正确识别听书业务中的核心对象，例如专辑、章节、主播、作者、会员、订单、推荐位、榜单和专题
- 可以完成一次完整的“用户提问 -> 问题理解 -> 分析执行 -> 结果生成 -> 返回结果”的闭环演示
